
# SkillSwap+ – Time-Based Skill Exchange Platform

A full-stack web application that enables users to exchange skills using a time-credit system, promoting collaborative learning and peer-to-peer knowledge sharing.

---

## 🚀 Overview

SkillSwap+ is designed to connect users who want to learn and teach different skills without monetary exchange. Instead, users earn and spend **time credits**, making skill-sharing accessible and community-driven.

---

## 🔑 Key Features

- ⏱️ **Time-Based Economy**: Earn credits by teaching, spend credits to learn  
- 👥 **User Matching**: Connect with users based on skill requirements  
- 💬 **Real-Time Chat**: Seamless communication using Socket.io  
- 🔐 **Secure Authentication**: JWT/OAuth-based login system  
- 🔔 **Notifications System**: Real-time updates for requests and interactions  
- 🌐 **Responsive UI**: Deployed and accessible across devices  

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Firebase (Authentication & Database)  
- **Real-Time Communication**: Socket.io  
- **Deployment**: Vercel
